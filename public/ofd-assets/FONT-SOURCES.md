# OFD fallback fonts

- `gkai00mp.ttf` and `gbsn00lp.ttf` are unmodified AR PL KaitiM GB and AR PL SungtiL GB 2.11 from the [Debian Kaiti source archive](https://deb.debian.org/debian/pool/main/f/fonts-arphic-gkai00mp/fonts-arphic-gkai00mp_2.11.orig.tar.xz) and [Debian Sungti source archive](https://deb.debian.org/debian/pool/main/f/fonts-arphic-gbsn00lp/fonts-arphic-gbsn00lp_2.11.orig.tar.xz). See [ARPHICPL.TXT](ARPHICPL.TXT).
- `LiberationSerif-*.ttf` are unmodified [Liberation Fonts 2.1.5](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5). See [LICENSE-Liberation.txt](LICENSE-Liberation.txt).
- `Inconsolata-*.ttf` are unmodified [Inconsolata static TrueType fonts](https://github.com/googlefonts/Inconsolata/tree/9cd7f73c80b54bd5751f481c84db50141771148d/fonts/ttf). See [LICENSE-Inconsolata.txt](LICENSE-Inconsolata.txt).
